# Cryptid Field Research Collective

Welcome to the shared workspace of the Cryptid Field Research Collective. This repository contains our ongoing documentation of cryptid sightings, field sketches, and expedition records.

## Structure

- **field-guides/** — Species profiles compiled from eyewitness accounts and historical records
- **sketches/** — Visual documentation from field researchers and archival sources
- **journal/** — Expedition logs and operational planning

## Contributing

All field notes must be encrypted before upload. If you're reading this in plaintext, something went very right (or very wrong).

New researchers: coordinate with the workspace owner before your first upload. Your submissions will appear as pending until approved.

## A Note on the Witte Wieven

Yes, we included Dutch fog ghosts. No, this is not scope creep. The collective recognises that cryptozoology is not exclusively an American discipline, and frankly the wieven have better primary sources than half the North American catalogue.
